# 擷取重點（摘要，非原文）

- 韓國學生簽證主要分 D-2（大學以上正規課程、交換生）和 D-4（語學堂等一般研修）。
- 交換生即使只去一學期，也要申請 D-2。
- 文章描述的流程：取得入學許可 → 準備個人文件 → 審查 → 核發簽證認證號碼 → 向駐台北韓國代表部申請 → 核發簽證 → 入境。
- 停留 90 天以下的短期語學堂可用 K-ETA 免簽入境，但交換一學期不適用。
- 交換生補充文件舉例：母校推薦信、交換學生證明、財力證明等。
